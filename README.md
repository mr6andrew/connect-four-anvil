# Connect Four: Anvil

Terminal Connect Four in C++17 with player-vs-player and player-vs-computer modes, win detection, input validation, and a custom one-use anvil mechanic. Demonstrates object-free game-state design, vectors, control flow, and defensive input handling.

## Highlights

- Player-versus-player and player-versus-computer modes
- Horizontal, vertical, and diagonal win detection
- Defensive computer strategy that checks winning and blocking moves
- Input validation, randomized turn order, replay support, and board rendering

## Build and run

```bash
make
./connect_four_anvil
```
